# Ильсур ловит члены

Закрытая браузерная аркада для компании друзей.
Проект находится в разработке. Основа задачи 02: стартовая страница и
`GET /api/health`. Игра, вход и рейтинг пока не реализованы.

## Окружение и установка

Node.js 22.12+ и npm (`nvm use`, если установлен nvm).

```sh
npm install
npx playwright install chromium webkit
```

Первая установка создаёт `package-lock.json`: его необходимо проверить
и включить в согласованный коммит. После этого использовать `npm ci`.
Lock-файл создан реальной установкой npm. Чистая повторная установка
`npm ci` пока не проверена из-за сетевых ограничений среды разработки.

## Разработка

```sh
npm run dev
```

Открыть http://localhost:5173. Vite проксирует `/api` к Fastify на
http://127.0.0.1:3000. Завершение двух процессов: Ctrl+C.
Порты 5173 и 3000 должны быть свободны.
Телефон: одна Wi-Fi сеть с Mac, адрес `http://<IP-Mac>:5173`.
Стартовая страница доступна в обеих ориентациях; игровая ориентация — задача 05.

## Сборка и запуск одним сервером

```sh
npm run build
npm start
```

Открыть http://127.0.0.1:3000. Fastify раздаёт `dist/client` и API.
По умолчанию `.env` автоматически не читается. При необходимости:

```sh
cp .env.example .env
node --env-file=.env dist/server/main.js
```

`HOST` по умолчанию `127.0.0.1`, `PORT` — `3000` (диапазон 1–65535).
Для доступа к собранному серверу из локальной сети задать `HOST=0.0.0.0`.
Общий пароль ещё не реализован; публичное размещение — отдельная задача.

## Проверки

```sh
npm run typecheck
npm run build
npm test
npm run test:e2e
npm run format:check
```

`npm run check` запускает сборку, тесты покрытия и браузерные тесты.
Playwright сначала собирает проект и запускает сервер на свободном порту 3000.
Отчёты: `coverage/index.html`, `coverage/coverage-summary.json`.
Порог 100% строк, функций, ветвей и statements. Включены все файлы
исполняемого кода в `server`, `client`, `scripts`, включая неимпортированные.
В клиенте сейчас только HTML/CSS; собственных служебных скриптов нет.

Визуальных эталонов пока нет. На Linux с версией Playwright из lock-файла:

```sh
npm run build
npm run test:visual -- --update-snapshots
```

Просмотреть каждый PNG в `tests/e2e`: читаемость, отсутствие обрезки,
размеры 1280×720, 844×390 и 390×844, Chromium и WebKit.
Только проверенные эталоны включать в коммит. Обновление не означает приёмку.
Обычный запуск без эталонов завершится ошибкой; skip не используется.
Для частичной проверки поведения на macOS:
`npm run test:e2e -- --grep-invert @visual`. Это не заменяет полный Linux CI.

| Критерий                            | Проверка                                                 |
| ----------------------------------- | -------------------------------------------------------- |
| API, статика, CSS, 404              | `tests/unit/app.test.ts`, E2E собранного сервера         |
| Параметры и ошибки запуска          | `tests/unit/config.test.ts`, `tests/unit/main.test.ts`   |
| Типы и сборка                       | `npm run build`                                          |
| Клавиатура, ссылка, ошибки страницы | `tests/e2e/foundation.spec.ts`                           |
| Размеры ПК/телефона и внешний вид   | layout и visual тесты того же файла                      |
| Воспроизводимость                   | чистый `npm ci`, Linux CI после появления lock-файла     |
| Отсутствие секретов                 | проверка diff и `dist/client`, секреты только на сервере |

## Статус проверки

После установки `@fastify/static@10.1.11` сборка, типы и 17 модульных/
интеграционных тестов прошли. Покрытие: 100% строк (16/16), функций (3/3),
ветвей (11/11), statements (18/18). Форматирование проверено.

Пользователь подтвердил прохождение всех 14 браузерных тестов на macOS
после исправления клавиатурного теста WebKit. Для ссылок используется
Option+Tab в macOS WebKit; реальная проверка фокуса и Enter сохранена.
Все 6 macOS снимков просмотрены: текст и ссылка читаемы, обрезки нет.

Установлены `@fastify/static@10.1.11`, `glob@14.0.6`, `minimatch@11.0.9`;
lock-файл обновлён. Итог повторного online `npm audit` пока не получен.

Оставшиеся проверки: чистый `npm ci`, Linux эталоны и успешный Ubuntu CI,
ручной просмотр страницы владельцем на компьютере и телефоне.
Снимки macOS не заменяют эталоны Linux. Среда агента запрещает открытие
локального порта, поэтому браузерный запуск выполнен пользователем.
Задача передана в Check & Release с перечисленными блокировками,
готовность к выпуску не подтверждена. Коммит и PR отсутствуют.
