# Общая фоновая музыка

Добавляйте сюда MP3 с именами `01.mp3`, `02.mp3`, `03.mp3` и так далее.
При сборке Vite подхватывает файлы с расширением `.mp3` в нижнем регистре.
Порядок воспроизведения определяется именами файлов. После добавления музыки
пересоберите проект командой `npm run build` или перезапустите `npm run dev`.
